Test data

Test data const objects are smaller datasets designed to be used in tests for other packages. They include both Date and DateTime objects. All but one of the objects has an empty TimeArray meta field.

constDescriptionFirst timestampNumber of rows
opsingle column Date data2000-01-03500
clsingle column Date data2000-01-03500
ohlcfour-column Date data2000-01-03500
ohlcvfive-column Date data2000-01-03500
mdata1-column Date data with meta field2000-01-03500
datetime11-column DateTime data2013-12-31T00:00:005
datetime21-column DateTime data1961-12-31 00:00:005
